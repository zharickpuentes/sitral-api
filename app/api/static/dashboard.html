Resiliencia de las APIs externas (circuit breaker)

3 fallos consecutivos → OPEN (las llamadas se rechazan y se sirve la caché) · al vencer el tiempo de recuperación → HALF_OPEN (1 llamada de prueba) · si la prueba funciona → CLOSED. Cada llamada usa reintentos con backoff exponencial.
